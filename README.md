# Featured Project

## SBI-AMCC Bank Loan Portfolio Audit Dashboard

### Power BI · Power Query · Excel · Banking Audit

A portfolio analytics and audit dashboard designed to demonstrate how banking credit data can be analysed using **Power BI and Power Query**.

The project focuses on areas such as:

- Loan portfolio overview
- Borrower segmentation
- Agriculture & MSME exposure
- Outstanding loan analysis
- Risk indicators
- Documentation compliance
- Security and insurance observations
- Irregularities and exceptions
- Audit-focused monitoring

### Project Purpose

The objective is to demonstrate the application of **data analytics to banking audit and credit monitoring** rather than simply presenting a generic Power BI dashboard.

### Data Disclaimer

> **This project is a personal learning and portfolio project built entirely using synthetic data. No actual borrower, account, transaction, client, or bank data has been used. The dataset structure and scenarios are inspired by concepts encountered during banking audit work, but all records, values and observations presented in this project are fictional.**

### Tools Used

`Power BI` · `Power Query` · `Microsoft Excel`
